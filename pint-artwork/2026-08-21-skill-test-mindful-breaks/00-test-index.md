# Pinterest Checklist Planner Test — Mindful Breaks

This package tests the reusable Pinterest Checklist Planner with a new wellness category, three checklist ideas, post-ready metadata, visual directions, and publishing controls.

| Folder | Purpose |
|---|---|
| `01-content-plan` | Category, Board, section, title sequence, and topic tags. |
| `02-visual-templates` | Production directions and managed graphic status. |
| `03-pin-metadata` | Titles, descriptions, alternative text, and template assignments. |
| `04-publishing` | Draft-to-published status control. |
