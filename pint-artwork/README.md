## Standard package structure

| Folder | Use |
|---|---|
| `01-content-plan/` | Categories, Boards, sections, title lists, and Pin ranges. |
| `02-visual-templates/` | Visual rules, asset manifests, and pending production briefs. |
| `03-pin-metadata/` | Pin titles, descriptions, alternative text, and template assignments. |
| `04-publishing/` | Status, intended dates, live URLs, and publishing notes. |
